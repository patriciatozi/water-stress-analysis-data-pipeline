# Identidade visual do dashboard

`pece-logo.png` é o logo branco do PECE / Escola Politécnica da USP, correspondente à
referência enviada pelo usuário. O PNG original foi obtido em 11/10/2026, preservando
seus bytes, transparência e proporções (224 × 91 px).

Fonte: [site do PECE](https://pecepoli.com.br/home/).
Arquivo: [logo-pece-white.png](https://pecepoli.com.br/wp-content/themes/pece/dist/img/logo-pece-white.png).

O dashboard incorpora o arquivo local no topo da barra lateral, sem requisições ao site
no momento da leitura. A imagem Docker inclui `assets/`.
